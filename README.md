# MG Tuition India

Small-batch live online tuition marketing site for Indian boards (CBSE, ICSE, Kerala State).

Built with Vite, React, TypeScript, Tailwind CSS, and Framer Motion.

## Setup

```bash
cd "MGTuition India"
npm install
npm run dev
```

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run preview` — preview production build

## Config

Edit contact numbers, offices, boards, and copy in `src/lib/site.ts`.

Forms currently open a prefilled `mailto:` to `info@mgtuition.com`. Replace `src/lib/email.ts` with a server API when ready.
